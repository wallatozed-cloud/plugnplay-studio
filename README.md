# Plug N Play Studio

Drop a photo or a document, write what should change, and get the edit.

A darkroom for photos and pages: restyle a photograph, rewrite a letter, or swap names, dates, and prices on a flyer. One instruction. The studio reads the original first, then makes the change.

## Use it

1. Choose a file, paste, or try a sample.
2. Write the change in your own words.
3. Tap **Rewrite**.
4. Compare, download, or keep going.

Put exact copy in quotes when it has to come out letter-perfect.

Photos: JPEG, PNG, HEIC, WebP, GIF.  
Pages: PDF, Word, text, Markdown.

## Run locally

```bash
npm install
npm run dev
```

Needs an `XAI_API_KEY` in the environment for edits.

## Stack

TanStack Start, React, Tailwind, xAI (Grok + Imagine).
